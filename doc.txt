Installation d'Apache Ant
Télécharger depuis https://ant.apache.org/bindownload.cgi

Version recommandée : Apache Ant 1.10.x (compatible Java 8)
Fichier : apache-ant-1.10.14-bin.zip
Extraire dans un répertoire, par exemple :

C:\dev\tools\apache-ant-1.10.14

Variables d'environnement à définir :

set ANT_HOME=C:\dev\tools\apache-ant-1.10.14
set JAVA_HOME=C:\dev\tools\java\jdk8u362-b09

set PATH=%ANT_HOME%\bin;%JAVA_HOME%\bin;%PATH%

set PATH=%JAVA_HOME%\bin;%PATH%

Vérifier l'installation :

ant -version
ant clean war
